Velkommen til Faseseparatoren

Sorter molekylerne, inden de rammer en affaldsspand!

Musen: træk molekylet i en spand (kan fortrydes før landing)
Piletaster: op/ned = vælg molekyle, venstre/højre = vælg fase
Enter: land det valgte molekyle med det samme (kun over en spand)

Rigtigt = penge. Forkert = renhed og penge tabt.

Teori

  • O eller N med H på → polært → Vandig fase
  • Ren kulbrinte (kun C og H) → upolært → Organisk fase
  • Lang kulbrintehale (4-5+ C pr. polær gruppe) vinder → Organisk fase
