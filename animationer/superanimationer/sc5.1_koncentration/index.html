Koncentration

Koncentrationen er stofmængden pr. liter opløsning. Enheden er mol/L, som skrives M.

n eller c? Stofmængden n er alt stoffet i glasset. Enheden er mol.
Koncentrationen c er stof pr. liter. Enheden er M = mol/L.
Hælder man halvdelen ud, halveres n, men c er den samme.
Formlen c = nV    n = c · V    V = nc

Rumfanget skal være i liter: 250 mL = 0,250 L. Kender man massen, findes stofmængden først: n = m / M.

Eksempel 14,61 g NaCl opløses til 250 mL
n = 14,61 g58,44 g/mol = 0,250 mol
c = 0,250 mol0,250 L = 1,00 M

Tapper man noget ud, er det den samme opløsning: c er den samme.

Fortynding Der kommer vand til, men ikke stof. Stofmængden er den samme før og efter:
cfør · Vfør = cefter · Vefter
